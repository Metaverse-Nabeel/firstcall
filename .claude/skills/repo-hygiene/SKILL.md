# Repo hygiene

This repo is **public from the first commit** and must contain **only graded
deliverables**. The history itself doubles as the Prior-Work Disclosure, so a stray file is
not just untidy — it is visible to the grader forever.

## Before every commit

Run, and read every line of output:

```bash
git status --short
git diff --cached --stat
```

Each staged path must be one of: **prototype** (`src/`, `app/`), **docs** (`docs/`),
**eval** (`eval/`, `fixtures/`), or **config** (root dotfiles, `package.json`, `scripts/`).
Anything else is working material and belongs in `../MUST-work/`.

Then scan the staged content:

```bash
git diff --cached | grep -nE 'AIza[0-9A-Za-z_-]{30,}|sk-ant-|gh[pousr]_|BEGIN [A-Z ]*PRIVATE KEY'
git diff --cached --stat | awk '$3 > 5000 {print "LARGE: " $1}'
```

Zero hits required on the first. Investigate every hit on the second.

## The two-tree rule

```
MUST/        ← the repo. Deliverables only.
MUST-work/   ← sibling, NOT a repo, never committed.
```

`MUST-work/` is a **sibling, not a subdirectory**, so `git add .` from inside the repo
cannot reach it. If you ever find yourself adding a `MUST-work` entry to `.gitignore`, the
directory is in the wrong place — move it, do not ignore it.

## Never in this repo

- `.env`, `.env.local`, or any real key. `.env.example` only, with placeholder values.
- `*.mp4` / `*.mov` — the demo video goes to Loom; only the link enters the README.
- Real or employer data of any kind. Registry, vendors and reports are wholly synthetic and
  generated by a committed script.
- `node_modules/`, `.next/`, `.DS_Store`.
- Anything pasted from a chat transcript without being read first.

## Whole-history scan

Before submission, and after any rebase or history edit:

```bash
git log -p | grep -nE 'AIza[0-9A-Za-z_-]{30,}|sk-ant-|gh[pousr]_'   # must be empty
git ls-files                                                       # read line by line
```

A secret removed in a later commit is **still in the history and still leaked**. If one is
found, rotating the key is mandatory and rewriting history is not sufficient on its own —
assume it was scraped.

## The hook is a backstop

`scripts/pre-commit` blocks key patterns, files named `.env`, and files over 5 MB. Install
it with `npm run setup:hooks`. It catches accidents; it does not replace reading
`git status`. Verify it still works by staging a dummy key and confirming the rejection.
