# D2 — design artifacts + agent core

Running total: **11.4h / 40**.

## Built
- `docs/design.md` — to-be journey (mermaid), service blueprint with a manual-ops lane,
  value model, operating model, what breaks at 120 stores.
- `src/llm/` — fixture cache, Gemini transport, mode-aware client.
- `src/agent/lexicon.ts`, `extract.ts`, `retrieve.ts`.

## Decided
- **Blueprint keeps a manual-ops lane.** Registry hygiene and policy upkeep are permanent
  human work the product *creates*. A diagram without that lane is a better sales asset and
  a worse plan.
- **Primary metric is warranty-leakage catch rate, not dollars saved.** Dollars arrive
  30–45 days late on an invoice; catch rate is readable the day the decision is made.
- **Not time-to-dispatch as primary** — it improves almost automatically and would flatter
  the product. Reported as a secondary instead.
- `c_extract` = weighted field agreement between LLM and lexicon, safety weighted 0.5.
  Disagreement on safety is the most diagnostic kind: if the lexicon sees a gas smell the
  model missed, that is exactly the case a human needs, and confidence should collapse.
- **Union, not intersection, on safety indicators.** Either extractor firing is enough.

## Found
- Fixture cache key must include `generationConfig`, not just the prompt. Otherwise a
  `thinkingLevel` change silently reuses answers from a different decoding regime — a quiet
  failure that would invalidate every number downstream.
