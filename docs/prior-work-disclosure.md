# Prior-Work Disclosure

**Everything in this repository was created during the sprint.** No component, document,
diagram or dataset predates it.

**The git history is the evidence.** This repository was made public at its first commit and
every commit is timestamped inside the sprint window. `git log --reverse` shows the sequence:
contracts and hygiene, then policy and registry, then the agent core, then the case set and
evaluation, then the written deliverables. Nothing was imported from a private repository or
squashed into an opening commit.

**Domain background.** I have prior professional exposure to multi-site facilities and asset
operations, which informed the problem selection and made the as-is workflow timings and
warranty-leakage assumptions realistic rather than invented. **No employer data, document,
system or code was used.** The asset registry, vendor list and all 60 breakdown reports are
wholly synthetic, generated by committed scripts from a pinned seed, and reproducible by
anyone running `npm run gen:registry`.

**Third-party dependencies.** Next.js, React, zod, vitest, tsx and TypeScript, all standard
and declared in `package.json`. Google Gemini via its public HTTP API. No proprietary
libraries, no paid datasets, no purchased templates.

**AI assistance** is disclosed in full in [`ai-tool-use.md`](ai-tool-use.md).

**Reuse of my own prior work:** none. No code, prose or diagram was carried in from an earlier
project.
